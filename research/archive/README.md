# Research archive

The current repository exposes the four RecoverGraph paper cases: GS-T006, GS-T007, GS-T008, and GS-T017. Additional development and invalid runs were excluded from the reported evaluation. The complete pre-cleanup research state remains in Git history and the `recovergraph-pre-public-cleanup` tag; Git history was not rewritten.

Older planning, dataset-construction, architecture, and benchmark-protocol documents are preserved under `legacy_docs/`. They describe earlier research phases and are not the authority for the four-case reported evaluation. Use `research/methodology.md`, `research/RESULTS.md`, and `research/REPRODUCIBILITY.md` for the current public evaluation.
